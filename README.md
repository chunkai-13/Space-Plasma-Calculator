# 太空電漿物理計算與單位查詢工具 (Space Plasma Calculator)

專為太空電漿物理研究量身打造的跨平台計算與單位查詢工具。

---

## 如何在電腦上開啟使用

您有以下兩種最簡單的方式在 Mac 上開啟使用：

### 方法一（一鍵啟動，推薦）：
* 直接在 Finder 中雙擊 **`啟動應用.command`** 檔案。
* 系統會自動啟動並在瀏覽器（Safari 或 Chrome）中開啟應用。

### 方法二（直接開啟）：
* 直接在 Finder 中雙擊 **`index.html`**，即可使用任何瀏覽器開啟。

---

## 如何在手機（iPhone 或 Android）上使用與加入主畫面

1. 確保您的電腦與手機在同一 Wi-Fi 網路下，或將專案透過 iCloud 雲碟同步至手機「檔案」App。
2. 若在電腦執行 `啟動應用.command`，畫面上會顯示您的電腦區網 IP（例如 `http://192.168.x.x:8080`），以手機瀏覽器開啟該網址。
3. **加入手機主畫面（如同原生 App）**：
   * **iPhone (Safari)**：點擊底部中央的「分享」按鈕 ➔ 往下滑點選「**加入主畫面**」。
   * **Android (Chrome)**：點擊右上角「三個點選單」 ➔ 點選「**安裝應用程式**」或「**新增至主螢幕**」。
4. 加入後，手機桌面上會顯示專屬太空圖示與名稱，點開即為全螢幕極簡介面，並支援離線運算。

## 核心功能說明

### 1. 自訂物理量計算（Physical Quantity Calculator）
* **自訂組合運算**：點擊「新增物理量」或「插入常用常數」，可自由指定分子、分母、前置係數、數值、單位與次方。
* **常用常數庫**：內建真空磁導率 $\mu_0$、介電常數 $\varepsilon_0$、波茲曼常數 $k_B$、基本電荷 $e$、質子質量 $m_p$、電子質量 $m_e$、光速 $c$ 等。
* **因次維度分析**：點擊「＝ 計算結果」，系統自動解析合成物理量因次，並提供「太空常用制（Space）」、「SI 制」、「CGS 制」三種制度的一鍵即時換算。
* **經典範例一鍵帶入**：上方按鈕可快速載入磁壓力 $B^2 / (2\mu_0)$、電漿 Beta、阿爾芬速度等公式。

### 2. 查找單位與換算（Unit Lookup & Converter）
* **雙層分類與關鍵字搜尋**：依類別分類，亦可輸入中文（如「磁場」）、英文（如「Magnetic Field」）或符號代碼（如「B」）進行即時搜尋。
* **多制度規格表**：並列展示 SI、CGS 與太空常用單位之定義與換算係數。
* **即時換算器**：輸入任意數值，即時顯示目標單位數值與需乘上的倍率公式。

### 3. 太空物理方程式計算（Space Physics Equations）
* **完整收錄領域**：
  * 單粒子運動：迴旋頻率、迴旋半徑、第一絕熱不變量（磁矩 $\mu$）、$E \times B$ 漂移、$\nabla B$ 與曲率漂移。
  * MHD 與波動：阿爾芬速度 $v_A$、離子聲速 $c_s$、電漿 Beta 值 $\beta$、磁能密度。
  * 電漿特徵尺度：電漿頻率 $\omega_{pe}$、德拜長度 $\lambda_D$、德拜球粒子數、慣性長度 $d_i, d_e$。
  * 震波跳躍條件：Rankine-Hugoniot 垂直激波跳躍條件、壓縮比 $r$、壓力跳躍、磁場跳躍。
  * 速度分布函數：Maxwellian 分布與特徵熱速度、Kappa 分布（Suprathermal 尾巴）、正則化 Kappa 分布（RKD）。
  * 電磁能通量：Poynting 能通量 $S$、電磁能量密度。
* 每個方程式皆提供直觀公式卡片、單位自由切換與詳細結果清單。

### 4. 介面個人化設定
* **深色／淺色模式**：點擊頂部右上角太陽/月亮按鈕即可無縫切換。
* **繁體中文／英文**：點擊頂部語言按鈕即可即時切換。
